## 1. Чем отличается Git от GitHub?
Git — это программа для контроля версий. Работает локально на компьютере.
GitHub — это сайт (облако), где хранятся Git-репозитории и удобно работать в команде.

## 2. Для чего используется виртуальное окружение Python?
Чтобы у каждого проекта были свои библиотеки.
Оно изолирует зависимости, чтобы не смешивать разные проекты.

## 3. Что такое commit, branch, remote, pull request?
commit — сохранение изменений в истории проекта.
branch — отдельная ветка для разработки.
remote — удалённый репозиторий.
pull request — запрос на слияние изменений из одной ветки в другую.

## 4. Зачем нужен файл .gitignore?
Он сообщает Git, какие файлы и папки не нужно добавлять в репозиторий.

## 5. Как организовать командную работу над бизнес-приложением с помощью Git?
1) Создать общий репозиторий на GitHub.
2) Каждый делает свою ветку под задачу.
3) Делает commit и push своей ветки.
4) Создаёт Pull Request в main.
5) Другой участник проверяет и делает merge.
6) Все обновляют main через git pull origin main.

## 6. Какие файлы обязательно должны быть в репозитории учебного проекта?
README.md — описание проекта.
.gitignore — список игнорируемых файлов.
requirements.txt — зависимости проекта.
main.py — точка входа в программу.
docs/business_requirements.md — бизнес-требования.

## 7. Что произойдёт, если два разработчика изменят один и тот же файл в разных ветках?
Будет конфликт и Git покажет, какие строки не совпали.
Нужно вручную выбрать правильный вариант, сохранить файл, сделать commit и завершить merge.
