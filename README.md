## 3. Архитектурный стиль
**Слоистый монолит с элементами Clean Architecture.**

Данный стиль выбран по следующим причинам:
- команда состоит из 4 человек;
- MVP требуется сдать в сжатые сроки
- ядро бизнес-логики не зависит от внешних систем, что упрощает тестирование и замену инфраструктуры;
- границы между модулями заданы явно, поэтому выделение сервиса не осложнено.
